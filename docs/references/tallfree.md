# Tallfree

[Tallfree](https://github.com/Mudb0y/tallfree) is a screen reader for the SP-404MKII,
using the same v5.52 APP1 image. Its named symbols and function-coverage repair helped
this analysis. See [the attribution and licence](../../THIRD_PARTY_NOTICES.md).

If desired, clone it locally into `resources/repos/tallfree/` for reading.
It is not needed to build Jam Tricks.
