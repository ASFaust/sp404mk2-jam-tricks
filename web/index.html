Jam Tricks

I use my SP-404MKII at jam sessions, playing along with my guitar. A few things got in the way there: in chromatic mode half the pads go dark once you pick a scale, the effect screen closes in the middle of a song, and I wanted to tune the guitar right on the sampler. So I changed its firmware.

These are those changes, free for anyone: scale pads, chromatic voice modes, a guitar tuner and a better time stretch. This page makes them to the firmware file you give it.

Everything happens in your browser. The file is not uploaded anywhere.

1Roland’s firmware

Download the SP-404MKII system program from Roland’s website (a zip file such as sp404mk2_sys_v552.zip) and choose it here. The bare SP404MKII_APP1.bin from inside it works too.

    Installing

    1. Format an SD card as FAT32 (a fresh format avoids trouble).
    2. Copy the built SP404MKII_APP1.bin to the top level of the card, with exactly that name.
    3. With the SP-404MKII off, insert the card, hold SHIFT and switch it on.
    4. Press the VALUE knob to start the update.
    5. Wait until the screen shows UPDATE COMPLETE!, then switch off and on again. Don’t switch off before that message.

    To go back to Roland’s firmware, install Roland’s own SP404MKII_APP1.bin from the zip the same way. Keep the zip for that.

    Good to know

    • Only the main program (SP404MKII_APP1.bin) changes. The sound chip’s firmware (SP404MKII_APP0.bin) is never touched.
    • The page checks every byte it changes against what it expects to find, and builds nothing if the firmware differs. For now it works with Roland’s version 5.52 only; support for later versions is in progress.
    • Some patches store settings in your projects that an SP-404MKII without the patch reads differently. Those patches say so above.
    • This is an independent project, not made or supported by Roland. Use it at your own risk.
